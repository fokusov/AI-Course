# Курс «ИИ-агент для 1С-разработчика»

Этот репозиторий — источник учебных материалов курса. В Git отслеживаются материалы курса; рабочий каталог автора хранится локально и исключён через `.gitignore`.

## Структура

- [`course/`](course/index.md) — материалы, которые можно публиковать на сайте;
- `course/getting-started/` — установка и подготовка рабочего места;
- `course/quickstarts/` — необязательные короткие практикумы;
- `course/lessons/<номер>-<тема>/lesson.md` — текст урока для ученика;
- `course/lessons/<номер>-<тема>/instructor.md` — сценарий преподавателя, который не публикуется;
- `course/lessons/<номер>-<тема>/references/` — связанные с уроком исследования, эталоны и справочные материалы;
- `course/lessons/<номер>-<тема>/homework/` — будущие задания и критерии проверки, когда они появятся;
- `docs/author/` — локальные концепция, методика, планы, аудиты и рабочие документы автора; каталог намеренно не отслеживается Git.

## Правило публикации

Точный белый список находится в [`course/publication-manifest.yaml`](course/publication-manifest.yaml). Публичная сборка берёт только:

- `course/index.md`;
- `course/getting-started/**/lesson.md`;
- `course/quickstarts/**/lesson.md`;
- `course/lessons/**/lesson.md`;
- специально перечисленные материалы из `course/lessons/**/references/`.

Файлы `instructor.md` и весь каталог `docs/author/` в сайт не попадают. Простого правила «публиковать весь Markdown» для этого репозитория недостаточно.
