# Курсы ИИ-разработки в 1С

Этот репозиторий — источник учебных материалов действующего курса и проекта отдельного сложного курса. В Git отслеживаются материалы курсов; рабочий каталог автора хранится локально и исключён через `.gitignore`.

## Структура

- [`course/`](course/index.md) — материалы, которые можно публиковать на сайте;
- [`advanced-course/`](advanced-course/README.md) — расширенный курс по сложной 1С-разработке с ИИ-агентами; имеет отдельный публикационный список, практический стенд ещё готовится;
- `course/getting-started/` — установка и подготовка рабочего места;
- `course/quickstarts/` — необязательные короткие практикумы;
- `course/lessons/<номер>-<тема>/lesson.md` — текст урока для ученика; действующий порядок находится только в `course/index.md`;
- `course/lessons/<номер>-<тема>/instructor.md` — сценарий преподавателя, который не публикуется;
- `course/lessons/<номер>-<тема>/references/` — связанные с уроком источники, контрольные данные и рубрики;
- `docs/author/` — локальные концепция, методика, планы, аудиты и рабочие документы автора; каталог намеренно не отслеживается Git.
- `docs/author/archive/2026-09-26-advanced-course/` — сохранённая прежняя редакция сложного курса; текущий маршрут находится в `advanced-course/README.md`.

## Правило публикации

Для каждого курса задан отдельный список разрешённых файлов:

| Курс | Список | Адрес на сайте | Главная страница |
|---|---|---|---|
| Базовый | [course/publication-manifest.yaml](course/publication-manifest.yaml) | `/ru/courses/ai-for-1c/` | `course/index.md` |
| Расширенный | [advanced-course/publication-manifest.yaml](advanced-course/publication-manifest.yaml) | `/ru/courses/advanced-ai-for-1c/` | `advanced-course/README.md` |

Пути в `publicFiles` считаются относительно каталога своего манифеста. Сборка сайта читает только явно перечисленные файлы. Новый Markdown-файл не становится публичным автоматически. `excludedPatterns` запрещает публикацию совпавшего файла даже при ошибочном добавлении в список.

Файлы `instructor.md`, материалы вне allowlist и весь каталог `docs/author/` в сайт не попадают. Прежние редакции уроков доступны в истории Git. Простого правила «публиковать весь Markdown» для этого репозитория недостаточно. Публикация сайта требует отдельного решения после проверки уроков.

### Подключение расширенного курса

Главная страница берётся из `README.md`, порядок чтения — из `publicFiles`. Уроки идут по номерам; правила и контрольные данные располагаются рядом со своим уроком. Описание стенда и источники находятся в конце как справочные материалы.

Локальные ссылки преобразуются в адреса страниц сайта только для файлов из публикационных списков. Ссылки из расширенного курса на введение, подготовку и урок 8 ведут на соответствующие страницы базового курса. Выход за пределы двух разрешённых списков, неизвестный файл или отсутствующий якорь должны останавливать сборку. Внешние HTTPS-ссылки сохраняются.

Не копируй каталоги целиком в публичные ресурсы сайта. Исходники базы, резервные копии, авторские ответы, журналы, архивы и служебные манифесты не являются учебными страницами. `pdf-manifest.json` управляет только локальным PDF и не расширяет список публикации сайта.

При подключении курса обнови каталог страниц сайта вместе с загрузчиком манифеста. Проверь, что доступны все 15 разрешённых документов, работают ссылки между курсами, а в результат сборки не попали исключённые файлы. Изменения публикационного списка также требуют проверки каталога и ссылок.

На страницах нужно сохранить предупреждение о подготовке практической части. Публикация текстов не означает, что стенд и задания уже прошли полный запуск в 1С. Этот репозиторий задаёт состав материалов; подключение к сайту и развёртывание выполняются отдельно.

## Текущая точка входа

Начни с [единого маршрута курса](course/index.md). Уроки усложняются по мере практики; после безопасности можно выбрать Demo83 или собственный разрешённый проект.

## PDF для чтения

На Windows собери актуальную версию одной командой из корня проекта:

```powershell
.\scripts\build-course-pdf.ps1
```

Результат: `output/pdf/ai-for-1c-course.pdf`. Скрипт читает только `publicFiles` из публикационного списка: сначала маршрут и уроки по порядку, затем подготовку и справочные материалы. Ссылки между включёнными страницами ведут внутрь PDF, внешние URL остаются активными; заголовки доступны через закладки. Если локальная ссылка ведёт за пределы списка или к несуществующему заголовку, сборка завершится ошибкой.

Нужны Pandoc и Python с `reportlab`. Скрипт сначала ищет Python, поставляемый с локальным Codex; если его нет, использует обычный `python`. Для обычного Python установи зависимость командой `python -m pip install reportlab`. PDF локальный и не включается в Git или публикацию сайта.

Расширенный курс собирается отдельно:

```powershell
.\scripts\build-advanced-course-pdf.ps1
```

Результат: `output/pdf/advanced-ai-for-1c-course.pdf`. Состав и порядок заданы в
`advanced-course/pdf-manifest.json`; авторские материалы не включаются. Оглавление,
закладки и внутренние ссылки ведут к разделам PDF. Ссылки на вводный курс открывают
его страницы в GitHub. Требуются Pandoc и Python с `reportlab` и `pypdf`.
Сборщик проверяет ссылки в итоговом PDF и заменяет прежний файл только после успеха.
Параметры: `--output <путь.pdf>` и необязательный `--report <отчёт.json>`.
