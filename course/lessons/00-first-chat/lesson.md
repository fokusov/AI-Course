# Урок 0. Первая полезная задача в чате

> Результат: ты получил ответ по небольшой 1С-задаче и проверил его на примерах. Для этого не нужны агент, Git и учебная база.

## Сделай сразу

На вымышленном примере попроси чат написать функцию 1С, которая принимает дату и возвращает начало следующего календарного месяца. Попроси примеры для обычной даты, декабря и даты со временем. До отправки подумай, что должно получиться для `20.12.2026 09:15:00`.

Прочитай ответ и проверь:

1. результат для декабря переходит в январь следующего года;
2. возвращается начало дня, а не прежнее время;
3. ты понимаешь каждую строку кода;
4. модель не добавила требований, которых не было в задаче.

Если строка неясна, попроси объяснить её на одном конкретном примере. Если результат неверен, покажи контрпример и попроси исправить. Не принимай фразу «должно работать» как проверку.

## Что чат знает о твоём проекте

Чат видит только переданный ему контекст. Он не знает состав твоей конфигурации, настройки базы и правила компании. Для первого урока рабочие данные и закрытый код не нужны. Если не уверен, что материал разрешено отправлять выбранному сервису, оставь его вне диалога. В [следующем уроке](../01-safety-and-route/lesson.md) ты выберешь безопасный контур для собственной задачи.

## Что взять с собой

Запоминать формулировку запроса или сдавать результат не нужно. Важен сам приём: придумай ожидаемый ответ до обращения к модели и покажи ей конкретный контрпример, если она ошиблась. Для незнакомой задачи можно попросить второй независимый диалог раскритиковать черновик, а замечания оценить самому.
