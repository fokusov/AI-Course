# Преподавателю: прайс-лист

До точного runbook проверьте версию УНФ и БСП, способ хранения цен, штатные API и возможность регистрации внешней обработки для регламентного вызова. Не обещайте универсальную команду запуска. Подготовьте четыре синтетические строки и отдельную восстанавливаемую базу. Пилот должен включать первый и повторный запуск, ошибочную строку, нативное открытие точного EPF и доказательство выполнения задания.

Если расписание недоступно, проведите ручную часть и зафиксируйте `BLOCKED` только для регламентного этапа. Не заменяйте эту проверку скриншотом установленного расписания.
