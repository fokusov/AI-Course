# Урок 5. Дорабатываем типовой документ в расширении

> Результат: у одного документа УНФ есть новый учебный реквизит, команда печати и выгрузка XML. Каждая часть принята отдельно.

Используй принятое расширение из [урока 4](../04-unf-extension/lesson.md) и отдельную учебную УНФ. Конкретный документ и точки расширения выбираются после исследования закреплённой версии: переносить названия объектов из чужого релиза нельзя. Все проверки выполняются на синтетических данных.

## Итерация 1. Реквизит

Согласуй имя, тип, обязательность, начальное значение, место на форме и поведение старых документов. Попроси агента сначала показать точки расширения и preview. После минимального diff проверь запись, повторное открытие, старый документ и роль, которой поле недоступно для изменения. Не переходи к печати, если результат первой итерации не определён.

## Итерация 2. Команда печати

Зафиксируй, что именно должен содержать печатный результат: реквизиты документа, новый реквизит, заголовок и поведение при пустом значении. Сначала найди штатный механизм печати выбранной УНФ. Добавь только нужную команду и шаблон, проверь доступность, повторное открытие, заполнение параметров и отсутствие реальных данных на снимках результата. Снимок показывает внешний вид; значения сверяй с документом отдельно.

## Итерация 3. XML-выгрузка

Опиши контракт XML до кода: корневой элемент, поля, типы, кодировка, формат дат, пустые значения, экранирование спецсимволов и версия схемы. Укажи, куда может быть сохранён файл, что делать при существующем файле и ошибке записи. Агент сначала показывает пример XML на синтетическом документе и план обработки ошибок. После реализации открой выгрузку независимым XML-парсером и сравни значения с документом; проверь спецсимволы, пустой реквизит и отказ записи. Запрети сетевую отправку: в этом уроке файл остаётся в учебном контуре.

## Приёмка

В одной матрице сохрани три независимых решения `ACCEPT / REJECT / BLOCKED`. Итог всего урока `ACCEPT` возможен, только если нативно проверена точная версия CFE, реквизит сохраняется, печать показывает согласованные значения, XML валиден и соответствует контракту, а исходная типовая конфигурация не изменена. При ошибке в третьей итерации не выдавай первые две за завершённый общий результат. Следующий урок впервые добавит повторяемую загрузку данных из внешнего файла.
