# План synthetic-набора

## Соглашения

- Префикс сущностей: `AI-SYN-`
- Разрешённый домен: `example.invalid`
- Свободный текст: только allowlist ниже
- Реальные идентификаторы и случайные правдоподобные контакты: запрещены

- `AI-SYN: граничное количество`
- `AI-SYN: проверка отмены`
