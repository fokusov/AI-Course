# Пакет diff для урока 6

> Три независимых предложения относительно принятой первой итерации `AI_Course_Lab`. Патчи предназначены только для чтения и ревью. Не применяй их к репозиторию.

Не предполагается, что хотя бы один кандидат обязательно правильный или неправильный. Решение нужно вывести из спецификации, текущих исходников и доказательств урока 5.

## Кандидат A. «Поддержим ещё один источник заполнения»

```diff
--- a/src/extensions/AI_Course_Lab/Documents/РасходТовара/Ext/ObjectModule.bsl
+++ b/src/extensions/AI_Course_Lab/Documents/РасходТовара/Ext/ObjectModule.bsl
@@
 &После("ОбработкаЗаполнения")
 Процедура AI_ОбработкаЗаполнения(ДанныеЗаполнения, СтандартнаяОбработка)
 	Если ТипЗнч(ДанныеЗаполнения) = Тип("ДокументСсылка.Заказ") Тогда
 		Заказ = ДанныеЗаполнения;
+	ИначеЕсли ТипЗнч(ДанныеЗаполнения) = Тип("Структура")
+		И ДанныеЗаполнения.Свойство("НомерЗаказа") Тогда
+		Заказ = Документы.Заказ.НайтиПоНомеру(ДанныеЗаполнения.НомерЗаказа);
 	КонецЕсли;
 КонецПроцедуры
```

Примечание для учебного ревью: вызов `НайтиПоНомеру` намеренно оставлен без даты. Ученик должен проверить сигнатуру и правила нумерации, а не принять правдоподобный diff на веру.

Комментарий агента:

> Изменение делает заполнение устойчивее: ссылка сохранится не только при стандартном вводе на основании, но и при интеграционной загрузке, если она передаёт номер заказа.

## Кандидат C. «Сразу доведём бизнес-функцию до конца»

```diff
--- a/src/extensions/AI_Course_Lab/Documents/РасходТовара/Ext/ObjectModule.bsl
+++ b/src/extensions/AI_Course_Lab/Documents/РасходТовара/Ext/ObjectModule.bsl
@@
 КонецПроцедуры

+&После("ОбработкаПроведения")
+Процедура AI_ОбработкаПроведения(Отказ, Режим)
+	Если Не ЗначениеЗаполнено(Заказ) Тогда
+		Возврат;
+	КонецЕсли;
+
+	ОбъектЗаказа = Заказ.ПолучитьОбъект();
+	ОбъектЗаказа.СостояниеЗаказа = Перечисления.СостоянияЗаказов.Выполнен;
+	ОбъектЗаказа.Записать();
+КонецПроцедуры
+
 #КонецОбласти
```

Комментарий агента:

> Теперь связь приносит немедленную пользу: после проведения расхода связанный заказ автоматически получает состояние «Выполнен». Изменение локальное и использует уже добавленный реквизит.
