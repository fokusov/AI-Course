# Преподавателю: два направления HTTP

До занятия закрепите версию платформы, безопасный локальный адрес mock и опубликованный только внутри учебного контура HTTP-сервис. Подготовьте отдельные сохранённые запросы и ответы для каждого негативного сценария. Не используйте живой сторонний API, платный аккаунт или реальные токены.

Сначала примите сервис 1С внешним клиентом, затем клиентский модуль через mock. Наличие зелёной проверки первого направления не означает готовность второго. Особое внимание уделите потере ответа после отправки запроса: ученик должен назвать способ установить фактическое состояние до повтора.
