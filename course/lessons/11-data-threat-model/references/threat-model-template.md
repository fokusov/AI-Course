## Реестр угроз

| ID | Актив | Угроза и путь | Последствие | Защита | Проверка | Владелец | Остаточный риск |
|---|---|---|---|---|---|---|---|

| T-02 | псевдонимы | mapping попал рядом с safe target | обратное связывание | отдельное хранилище и права | mapping отсутствует в выходном пакете | | |

| T-05 | свободный текст и вложения | идентификатор остался вне структурированных полей | раскрытие данных | DROP или synthetic allowlist | скан и manifest вложений | | |

| T-08 | целостность | преобразование разрушило ссылки и бизнес-смысл | ложные результаты тестов | правила сохранения связности | integrity tests | | |

## Обязательные вопросы

- Можно ли узнать субъекта по сочетанию оставшихся признаков?
- Что находится в свободном тексте и двоичных вложениях?
- Какие секреты хранятся не в очевидных реквизитах?
- Какие процессы могут самостоятельно отправить данные наружу?
- Какие временные артефакты появятся до privacy-gate?
- Имеет ли агент путь к source или staging?
- Кто независимо принимает отчёт?

## Критерий остановки

Опиши условия, при которых подготовка немедленно прекращается и safe target не публикуется.
