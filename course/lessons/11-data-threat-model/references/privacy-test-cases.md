# Матрица privacy-проверок

| ID | Риск | Подготовка | Проверка | Ожидаемый результат | Evidence |
|---|---|---|---|---|---|
| P-01 | прямое исходное значение | synthetic-canary в source | поиск во всём выходном пакете | 0 совпадений | отчёт сканера |
| P-02 | значение в свободном тексте | canary в комментарии | запрос + файловый скан | 0 совпадений | запрос, отчёт |
| P-03 | production endpoint | фиктивный `prod.invalid` | инвентарь настроек | 0 prod, только allowlist | отчёт настроек |
| P-04 | mapping рядом с target | создать mapping в staging | список выходного пакета | mapping отсутствует | manifest |
| P-05 | потеря ссылок | связанные документы | проверка ссылок | 0 битых ссылок | runtime-отчёт |
| P-06 | нарушение устойчивости | один субъект в нескольких объектах | сравнить псевдонимы | одинаковы в заданной области | запрос |
| P-07 | разрушение сценария | частичное исполнение | прикладной тест | сценарий сохранён | YAxUnit/Vanessa |
| P-08 | неидемпотентность | повторный запуск | контрольные показатели | нет смеси состояний | два отчёта |
| P-09 | забытый backup | завершить подготовку | инвентарь staging | разрешённые файлы или пусто | акт удаления |
| P-10 | секрет в артефакте | тестовый canary-secret | скан source/log/evidence | 0 совпадений | отчёт сканера |

## Правила интерпретации

- `0 совпадений` доказывает отсутствие только перечисленных маркеров в проверенной области.
- Структурный PASS не доказывает полезность тестовых данных.
- Прикладной PASS не доказывает приватность.
- Любая найденная запрещённая строка переводит выпуск safe target в `BLOCKED`.
- Проверку и преобразование желательно выполнять разными механизмами.
