# Карта автоматизации проверок AI_Course_Lab

## Правила

- Для каждой строки выбирается один основной уровень: `YAXUNIT`, `VANESSA`, `NATIVE`, `MANUAL` или `NOT NEEDED`.
- Дополнительное свидетельство можно указать отдельно, но оно не заменяет основное наблюдение.
- Если точный тест пока невозможен, записывается `DEFERRED` и проверяемый блокер.

| Проверяемое поведение или риск | Основной уровень | Наблюдаемое ожидание | Минимальные данные | От какого дефекта защищает | Что не доказывает | Статус |
|---|---|---|---|---|---|---|
| XML расширения принимается платформой |  |  |  |  |  |  |
| При создании расхода на основании заказа ссылка заполняется |  |  |  |  |  |  |
| При ручном создании случайная ссылка не появляется |  |  |  |  |  |  |

| После проведения поле Заказ только для просмотра |  |  |  |  |  |  |
