# Матрица приёмки контроля исполнения

| ID | Исходное состояние | Действие | Ожидаемый результат | Уровень проверки |
|---:|---|---|---|---|
| A1 | Проведён заказ 10 шт., расходов нет | Открыть заказ | Осталось 10, состояние `Не начато` |  |
| A2 | Заказ 10 шт. | Провести расход 4 шт. | Осталось 6, состояние `Частично` |  |
| A3 | После A2 | Провести второй расход 6 шт. | Осталось 0, состояние `Выполнено` |  |
| A4 | Заказ 10 шт. | Попытаться провести расход 11 шт. | Отказ с количествами, остаток не отрицательный |  |
| A5 | Заказ 10 шт. | Одновременно провести два расхода по 6 шт. | Один получает прикладной отказ, итоговый расход не больше 10 |  |
| A6 | Два одинаковых товара в заказе | Провести суммарно допустимый расход | Строки агрегированы по товару |  |
| A7 | Два разных товара, один исполнен полностью | Открыть заказ | Общее состояние `Частично` |  |
| A8 | Полностью исполненный заказ | Отменить один расход | Остаток восстановлен, состояние пересчитано |  |
| A9 | Проведённый расход изменён | Перепровести | Старые движения заменены новыми |  |
| A10 | Расход без ссылки на заказ | Провести | Существующее проведение работает, движений исполнения нет |  |
| A11 | Непроведённый заказ | Провести связанный расход | Контролируемый отказ |  |
| A12 | Закрытый заказ | Провести новый связанный расход | Контролируемый отказ |  |
| A13 | Заказ имеет отгрузки | Попытаться отменить проведение заказа | Отказ без потери движений |  |
| A14 | Заказ частично отгружен | Увеличить количество и перепровести | Остаток увеличен |  |
| A15 | Заказ частично отгружен | Уменьшить ниже отгруженного и перепровести | Отказ, прежние движения сохранены |  |
| A16 | Расширение отключено после восстановления baseline | Открыть Demo83 | Типовое поведение доступно, учебные данные восстановлены |  |
| A17 | В заказе одна строка товара и одна строка услуги | Провести расход только товара | Товар исполнен, услуга остаётся неисполненной, общее состояние `Частично` |  |
| A18 | После A17 | Отразить исполнение услуги предусмотренным контрактом способом | Услуга исполнена, общее состояние пересчитано без складских движений услуги |  |

## Для каждого сценария дополнить

- минимальные данные;
- способ подготовки;
- автоматическая очистка или восстановление;
- отчёт/журнал;
- какой дефект сценарий действительно ловит;
- что он не доказывает.
