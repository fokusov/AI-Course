# Улика 3. Runtime-наблюдение

> Открывай после обновления дерева гипотез по улике 2.

Для одного воспроизведения преподаватель зафиксировал следующие наблюдения:

1. Платформа входит в `AI_ОбработкаЗаполнения` один раз.
2. В момент входа:

```text
ТипЗнч(ДанныеЗаполнения) = ДокументСсылка.Заказ
ДанныеЗаполнения = ссылка на выбранный исходный заказ
Заказ = пустая ссылка
```

3. Строка присваивания `Заказ = ДанныеЗаполнения` не выполняется.
4. Непосредственно перед выходом из метода `Заказ` остаётся пустым.
5. После выхода типовой алгоритм не сообщает об ошибке, форма открывается, ссылка остаётся пустой.

## Что наблюдение не доказывает

- почему условие перед присваиванием ложно;
- каким именно изменением исходников это вызвано;
- что в проекте нет второго независимого дефекта;
- что предложенное исправление уже проверено.
