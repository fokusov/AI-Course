# Архитектор агентной разработки в 1С

Три продуманных проекта, в которых ты передаёшь агентной системе полный инженерный цикл: от задачи и спецификации до реализации, проверок и сдачи. Ты задаёшь цель и границы, принимаешь существенные решения и оцениваешь доказательства. Исследование, подготовку спеки, её критику, код и проверки берут на себя агенты под управлением bsl-flow.

Мы строим учебный вариант **dark-factory**: участие человека сокращается до решений, которые система пока не может обоснованно принять сама. Компетентность разработчика остаётся опорой; повседневный способ работы становится архитектурным.

> Редакция от 27 сентября 2026 года. Тексты и контрольные данные подготовлены; стартовые комплекты и полный пилот ещё не выполнены. В [описании стенда](lab.md) разделены возможности bsl-flow и готовность наших задач. Публикационный manifest вводного курса не изменён.

## Три урока

| Урок | Задача 1С | Результат для архитектора |
|---|---|---|
| [1. Отгрузка с аналогами](lessons/01-substitute-shipment/lesson.md) | Корректное списание и история замен | Запустить SDD-цикл с консилиумом, принять спецификацию и проверить доказательство исполнения |
| [2. Комплектация и себестоимость](lessons/02-kit-assembly/lesson.md) | Сборка и ручная замена компонента | Передать системе изменение требований и получить согласованные код, тесты и новую приёмку |
| [3. Последний товар](lessons/03-last-item-race/lesson.md) | Ошибка при одновременном проведении | Управлять расследованием через факты, передать контекст и принять исправление по сопоставимому опыту |

В первом уроке есть образец входного поручения и учебная остановка после спеки. Во втором ты формулируешь изменение самостоятельно. В третьем ведущий агент меняется, а требования, факты и состояние работы сохраняются. У каждого урока несколько этапов и второй раунд; новые предметные модули сейчас не добавляются.

## Как начать

1. Прочитай [как работает агентная фабрика](factory.md): роли, фактический порядок bsl-flow, решения человека и пакет сдачи.
2. Проверь [подготовку практики](practice.md) и [учебный стенд](lab.md).
3. Пройди три урока по [программе](program.md), сохраняя реальные результаты.

Для правил и чисел используются [общий контракт учёта](accounting-contract.md) и отдельные наборы уроков. Основа — каркас «1С:Специалиста»; [источники](sources.md) объясняют, что взято у 1С и что придумано для курса.

## Входной уровень и приёмка

Ты понимаешь документы, регистры, запросы и проведение, читаешь BSL и diff, умеешь подготовить отдельный учебный контур. Установка инструментов и первый опыт SDD есть во [вводном курсе](../course/index.md). Здесь рост сложности связан с самостоятельным управлением целым процессом.

Приёмка оценивает и продукт, и работу архитектора: постановку, качество спеки, независимость проверок, управление изменением и достаточность сдачи. Количество написанных вручную строк и сообщений агентам не является мерой успеха.

Прежние конфигуратор, диспетчер и расследование прибыли сохранены в локальном архиве автора. Текущий маршрут состоит только из этих трёх уроков. Время прохождения будет определено пилотом.

## PDF для чтения

Из корня репозитория на Windows:

```powershell
.\scripts\build-advanced-course-pdf.ps1
```

Результат — `output/pdf/advanced-ai-for-1c-course.pdf`. Порядок 15 документов задаёт
`advanced-course/pdf-manifest.json`: программа, процесс и подготовка, затем каждый урок
с его правилами и данными, в конце источники. Авторские ключи и архивы не включаются.

В PDF есть активное оглавление, закладки и переходы к разделам. Ссылки на вводный курс
ведут к его страницам в GitHub; для них и внешних источников нужен интернет. Подсказки
раскрыты, схема процесса отображается диаграммой. Сборка проверяет локальные адреса,
якоря и ссылки в готовом PDF; при ошибке прежний PDF сохраняется.

Нужны Pandoc, Python с `reportlab` и `pypdf`, шрифты Arial и Consolas из Windows.
Скрипт использует Python из Codex, если он установлен, иначе обычный `python`.
Для обычного Python: `python -m pip install reportlab pypdf`. Сама сборка работает
без сети и не меняет публикационный список сайта. Другой путь задаётся через
`--output "C:\путь\advanced-course.pdf"`, JSON-отчёт проверки — через `--report`.
